# Contributing to ESMotion

Thanks for helping improve ESMotion.

1. Discuss large API or document-format changes in an issue before implementation.
2. Keep the runtime independent from host application business models.
3. Add tests for cancellation, reversal, reduced motion, lifecycle, and serialization changes.
4. Run `swift test` with the current Xcode release before opening a pull request.
5. Do not contribute proprietary animation code, private assets, or reverse-engineered Telegram implementation details.

By contributing, you agree that your contribution is licensed under Apache-2.0.
